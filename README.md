## 🚀 Featured Projects

### 🤖 [Grasp-WM — Robot-Aware Grasp Feasibility](https://github.com/lazinnerbracken-collab/grasp-wm)

**Robotics · Computer Vision · Physical Simulation**

A robotics research project investigating the gap between predicted robotic grasps and successful physical execution.

The project explores:

- Robotic grasp generation using Contact-GraspNet.
- Franka Panda robot simulation with MuJoCo.
- Inverse kinematics and impedance control.
- Collision detection, motion planning, and grasp feasibility evaluation.
- Experiments on YCB objects.

**Technologies:** Python, MuJoCo, Contact-GraspNet, NumPy, Robotics

### 🔊 [Lens Depth — Industrial Sound Anomaly Detection](https://github.com/lazinnerbracken-collab/lens-depth-project)

**Machine Learning · Statistical Learning · Audio Analysis**

A collaborative research project investigating methods for detecting abnormal industrial sounds using statistical depth and geometric distances.

The project explores:

- Pretrained audio representations and feature analysis.
- Statistical anomaly detection using Lens Depth.
- Fermat distance for geometry-aware analysis.
- Dimensionality reduction with UMAP.
- Clustering with K-Means and DBSCAN.
- Evaluation through anomaly detection metrics.

**Technologies:** Python, PyTorch, NumPy, Scikit-learn, UMAP, Statistical Learning
